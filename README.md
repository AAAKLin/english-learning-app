## ✨ 核心产品特色

### 1. 🎨 极简莫兰迪大地色系设计 (Morandi Earth Tones)
- **视觉护眼与高级美学**：摒弃传统高饱和刺眼蓝光，全面拥抱 **陶土茶褐 (`#9B674D`)**、**灰岩鼠尾草绿 (`#677D6B`)**、**温润燕麦米白 (`#F6F3ED`)** 与 **深碳陶黑 (`#2E2926`)**。
- **温润纸材质感**：犹如触碰原木纸品、素烧瓷器与羊绒织物般的呼吸质感，久读不疲惫。
- **细腻微交互**：3D 立体平滑翻转卡片、轻盈毛玻璃面板、柔和动态光晕反馈。

### 2. 📚 32+ 模块化高阶词库与自由分类
数据层与交互逻辑彻底解耦，轻松支持自由扩展与标签切换：
- 🌿 **哲思心境 (Mind & Philosophy)**：`Serendipity`, `Solitude`, `Ephemeral`, `Catharsis`, `Sonder`, `Epiphany`, `Nostalgia`, `Equanimity`
- 💼 **职场远见 (Leadership & Strategy)**：`Resilience`, `Catalyst`, `Meticulous`, `Pragmatic`, `Leverage`, `Paradigm`, `Synergy`, `Visionary`
- 🎨 **艺术感知 (Aesthetics & Sensory)**：`Petrichor`, `Eloquent`, `Mellifluous`, `Halcyon`, `Ethereal`, `Resonant`
- 🤝 **人性共情 (Humanity & Connection)**：`Empathy`, `Compassion`, `Altruism`, `Vulnerability`
- ⚡ **高频进阶 (High-Yield Fluency)**：`Lucid`, `Ubiquitous`, `Nuance`, `Imperative`, `Mitigate`, `Feasible`

### 3. 💡 费曼生活化速记 (Feynman Technique)
每一个生词卡片背面均提供生活化比喻、通俗意象与词根故事拆解，告别机械死记硬背。

### 4. ✍️ 智能造句工坊与温和 AI 纠错反馈
- 实时统计字数与造句记录。
- **温和纠错 (Gentle Correction)**：精准纠正习惯搭配、介词错用与标点规范，附带母语者解析。
- **Native Speaker 点金表达**：点拨母语者在真实日常与学术演讲中的高阶语感习惯。

### 5. 🔊 原生发音与双语朗读
- 借助 Web Speech API 原生引擎，支持单词纯正美音发音及用户造句语音回放。

### 6. 💾 纯前端无感持久化 (LocalStorage)
- 所有已掌握状态、造句历史、学习进度实时自动保存到本地，刷新页面永不丢失。

## ⌨️ 键盘快捷键指南

| 按键 | 功能操作 |
| :--- | :--- |
| `Space` (空格键) | 3D 翻转单词卡片查看释义/正面 |
| `←` (左箭头) | 切换至上一个单词 |
| `→` (右箭头) | 切换至下一个单词 |
| `Ctrl` + `Enter` | 快速提交造句并进行 AI 智能诊断 |

## 🛠️ 本地运行与开发

本项目为零依赖单文件纯原生架构，无需安装 Node.js 或构建工具：
1. 双击直接在任意现代浏览器（Chrome、Edge、Safari、Firefox）中打开 `index.html` 即可畅享完整体验。
2. 或使用简易 HTTP 服务运行：
   ```bash
   npx serve .
   # 或
   python -m http.server 8080
   ```
